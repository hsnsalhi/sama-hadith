# سماء الحديث · Sama al-Hadith

> L'univers interactif des narrateurs du Hadith

Application web immersive représentant les narrateurs du Hadith sous forme d'un univers étoilé, connectée en temps réel à une base de données Supabase.

## Fonctionnalités

- 🌌 Visualisation univers étoilé avec zoom/dézoom
- ⭐ Étoiles réalistes avec rayons de diffraction
- 🔗 Chaînes de transmission (isnad) interactives
- 🔍 Recherche en arabe et translittération
- 📖 Fiches détaillées : biographie, shuyukh, élèves, hadiths
- 🎨 Filtres par génération (Sahaba, Tabi'un, Muhaddithun, Rijal)
- 📱 Support mobile avec pinch-to-zoom

## Stack technique

- **Frontend** : HTML/CSS/JS vanilla (Canvas 2D)
- **Base de données** : Supabase (PostgreSQL)
- **Hébergement** : Vercel

## Données

- 46+ narrateurs historiques
- 57+ chaînes de transmission
- 10+ hadiths fondamentaux en arabe

## Déploiement

Ce projet est configuré pour un déploiement automatique sur Vercel à chaque push sur la branche `main`.
